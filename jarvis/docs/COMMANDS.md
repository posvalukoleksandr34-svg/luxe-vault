# Свои команды

Фраза → цепочка действий, **без обращения к модели** (быстро, бесплатно, предсказуемо). Страница **Команды**
(`/commands`) или попросите JARVIS: «создай команду „игровой режим“: открой Steam и Discord, громкость 30%».

## Пример: «Игровой режим»

Триггеры: `игровой режим`, `включи игровой режим`, `gaming mode`. Шаги:
1. `computer_open_app` {name: steam}
2. `computer_open_app` {name: discord} — «продолжать при ошибке»
3. `wait` 2 с
4. `computer_volume` {action: set, level: 30}
5. `say` «Игровой режим активирован.»

Сказать или написать: «Джарвис, включи игровой режим!» — слово-активатор, регистр, «ё/е» и знаки препинания
не важны, но оставшаяся фраза должна **точно** совпасть с одним из триггеров. Поэтому добавляйте несколько
вариантов («игровой режим», «включи игровой режим»). Всё, что не совпало, обрабатывает обычный агент.

## Типы шагов

| Тип | Что делает |
|---|---|
| `tool` | любой инструмент из каталога с аргументами (форма строится по его схеме) |
| `wait` | пауза до 120 с |
| `say` | ответ пользователю (и озвучка в голосе) |
| `notify` | уведомление во все каналы доставки |
| `agent` | передать текст обычному агенту (с моделью) — для шагов, где нужна «голова» |

У шага есть условие `when` (`weekday`, `weekend`, `morning`, `evening`, …) и флаг «продолжать при ошибке».

## Безопасность

* Политика разрешений проверяется **при сохранении** и **при каждом запуске**. Шаги уровня *restricted* и
  *forbidden* (например, `computer_run`) в командах запрещены.
* Шаги уровня *confirm* (закрыть приложение, печать текста…) без предварительного одобрения пропускаются с
  объяснением. «Одобрить заранее» можно только после повторного входа (пароль/2FA) — это осознанное решение.
* Команды не могут запускать другие команды (нет рекурсии), каждое действие пишется в журнал инструментов и аудит.
* Результат честный: если шаг не удался, JARVIS так и скажет («выполнена не полностью», ✓/✗ по шагам),
  а не «Готово».

## Лимиты

Не больше 100 команд на аккаунт; в коммерческом режиме — по тарифу (`custom_commands`).
