# Статус реализации

Обновлено: 2026-09-29, версия 0.1.0, API v1, схема БД 0003.

## Легенда

| Статус | Значение |
|---|---|
| **WORKING** | реализовано и проверено: автотестами и/или сквозным прогоном на запущенном Docker-стеке |
| **PARTIAL** | работает, но с оговоркой, указанной в примечании |
| **NEEDS AUTH** | код готов и проверен на имитации протокола; нужен ваш ключ или аккаунт внешнего сервиса, с настоящим сервисом не запускалось |
| **NEEDS MANUAL TEST** | код готов, но нужна проверка на реальном железе или в реальном окружении (микрофон, Windows, настоящий бэкап) |
| **NOT IMPLEMENTED** | не сделано |
| **NOT APPLICABLE** | невозможно в выбранной технологии (браузер) |

Сквозные прогоны делались в демо-режиме (`JARVIS_FAKE_LLM=true`): вместо ИИ работает детерминированный набор правил.
С настоящей моделью (OpenAI или Claude) JARVIS в среде разработки **не запускался** — ключей не было.
