# Голос

## Как это устроено

Страница **Голос** (`/voice`) и компактное окно **/mini**: микрофон слушает постоянно, детектор речи (Silero VAD)
работает прямо в браузере — на сервер уходят только ваши фразы. Ответ озвучивается по предложениям, пока модель
ещё пишет; можно перебить (barge-in) голосом или кнопкой «Перебить». Подтверждения рискованных действий — голосом
(«да» / «нет») или кнопками.

Состояния визуализатора: **ожидание**, **слушаю**, **думаю**, **выполняю** (инструмент), **говорю**, **ошибка**.
Сфера реагирует на громкость микрофона (слушаю) и речи (говорю).

## Настройки голоса («Настройки → Голос» или кнопка ⚙ на странице Голос)

| Параметр | Что делает |
|---|---|
| Синтез речи | Автоматически / ElevenLabs / OpenAI / Браузер (бесплатно) |
| Распознавание | Автоматически / Deepgram / OpenAI / Браузер |
| Голос | список голосов провайдера; ElevenLabs — включая ваши **клонированные** голоса; «Свой voice ID…» |
| Скорость | ElevenLabs 0.7–1.2, браузер 0.5–2; для OpenAI передаётся как указание стиля |
| Высота | только голоса браузера |
| Стиль речи | OpenAI: «спокойно, с лёгкой британской иронией» и т. п. |
| Прослушать | озвучивает тестовую фразу выбранным голосом (серверные голоса — не чаще 20 раз за 10 минут) |

Ассистента можно попросить и голосом: «говори быстрее», «смени голос на Brian» — инструмент
`voice_set_preferences`.

**Свой голос.** Создайте или клонируйте голос в ElevenLabs (Voice Lab) — он появится в списке, или вставьте его ID.
Используйте только голоса, на которые у вас есть права.

## Режим без рук (wake word)

Включается в настройках голоса. Микрофон слушает постоянно, но JARVIS отвечает только на фразы, которые начинаются
со слова-активатора: «Джарвис, открой Chrome», «Hey JARVIS, pause». Варианты написания распознавателем
(«джарвис», «жарвис», «jarvis», «эй/hey/ok джарвис») учитываются. Только «Джарвис» → «Слушаю.» и окно продолжения.
После ответа в течение *окна продолжения* (по умолчанию 8 с) можно говорить без активатора. Посторонние фразы
игнорируются (видно подпись «не для меня: …»).

Ограничения (честно):
* Активатор распознаётся в тексте фразы — фраза всё равно отправляется на распознавание. Настоящий локальный
  wake-word-детектор «Hey JARVIS» без отправки звука есть на голосовом сателлите (`satellite/`, openWakeWord),
  в браузере — нет.
* Вкладка/окно с голосом должно быть открыто (браузер не слушает микрофон в фоне без открытой страницы).

## Тарифы

Серверные STT/TTS стоят денег за минуту, поэтому в коммерческом режиме они доступны тарифам с функцией
`voice_premium` (см. docs/COMMERCIAL.md); остальным — голос браузера.
